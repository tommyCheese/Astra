# Skill authoring

1. Keep `SKILL.md` focused on the repeatable workflow.
2. Put detailed reference material in `references/`.
3. Put deterministic helpers in `scripts/`.
4. Validate the Draft and review its Diff before publishing.
5. Test the exact Draft snapshot in quick or trusted mode when execution is involved.
