## MODIFIED Requirements

### Requirement: 运行保存请求策略与生效推理策略

系统 SHALL 在创建运行时接受回答模式与允许的用户偏好，并 SHALL 持久化保存该次运行实际采用的不可变模式、请求策略和生效运行 profile 快照。

#### Scenario: 编译默认快速回答策略

* **WHEN** 用户以 standard 模式启动一次新运行
* **THEN** 系统记录快速推理、直接规划、关闭可选反思、固定轻量工具预算和基础校验作为生效策略
* **THEN** 用户已保存的可信策略不会被快速策略覆盖

#### Scenario: 编译可信模式策略

* **WHEN** 用户以 trusted 模式启动一次新运行
* **THEN** 系统使用持久化的推理强度、工具预算、规划与反思偏好
* **THEN** 系统记录完整校验所需的生效 profile

#### Scenario: 运行期间设置发生变化

* **WHEN** 用户在运行开始后修改回答模式或可信策略
* **THEN** 当前运行继续使用其已持久化的生效 profile 快照
* **THEN** 后续新建运行可以使用新的模式或请求策略

### Requirement: 策略编译器应用正确性与安全下限

系统 SHALL 根据回答模式、任务风险、任务复杂度、工具权限以及系统策略编译运行 profile，并且 **MUST NOT** 允许任一回答模式关闭强制性的权限检查、安全检查、Schema 校验、基础失败处理或 Artifact 引用清洗。

#### Scenario: 高风险任务请求快速直接执行

* **WHEN** 某个高风险任务在 standard 模式请求直接执行
* **THEN** 策略编译器仍根据系统策略提升实际所需的审批或安全限制
* **THEN** 快速模式不会绕过被禁止操作或部署硬上限

#### Scenario: 关闭反思功能

* **WHEN** 快速 profile 或 trusted 用户策略禁用模型驱动反思
* **THEN** 运行时不再调用可选的模型反思
* **THEN** Schema 校验、有界重试、权限门控、重复操作防护以及该模式要求的完成处理仍保持启用
