## MODIFIED Requirements

### Requirement: 推理强度控制有界思考资源

系统 SHALL 将快速（fast）、平衡（balanced）和深度（deep）Agent 推理强度映射为明确的计划深度、候选策略数量、反思预算、工具与轮次预算以及验证覆盖范围等运行编排限制。显式模型思考配置存在时，模型调用的思考开关与深度 SHALL 由该模型配置独立决定；仅在显式配置缺失时，系统 SHALL 为旧客户端兼容而使用 Agent 推理强度推导模型思考参数。

#### Scenario: 快速推理执行简单任务

* **WHEN** 一个低风险的单步骤任务采用快速 Agent 推理且没有显式模型思考配置
* **THEN** 生效策略允许采用最小化计划及较低的兼容模型思考预算
* **THEN** 强制完成准则和安全检查保持不变

#### Scenario: 深度推理评估多个方案

* **WHEN** 一个复杂任务采用深度 Agent 推理
* **THEN** 生效策略允许生成多个候选策略、执行假设检查，并提供更高但仍受限的反思覆盖范围
* **THEN** 所有新增的模型调用均计入该运行记录的预算

#### Scenario: 显式模型思考深度独立生效

* **WHEN** 用户同时选择深度 Agent 推理和当前模型支持的低思考深度
* **THEN** 系统使用深度 Agent 推理对应的计划、工具、反思和验证资源
* **THEN** 系统使用低思考深度对应的 Provider 模型参数
