## MODIFIED Requirements

### Requirement: 推理强度控制有界思考资源

系统 SHALL 将快速（fast）、平衡（balanced）和深度（deep）推理映射为明确的计划深度、候选策略数量、模型请求推理强度、模型思考预算、反思预算以及验证覆盖范围等资源限制；当 Provider/模型支持推理控制时，实际模型请求 SHALL 使用该次 Run 的不可变生效策略。

#### Scenario: 快速推理执行简单任务

* **WHEN** 一个低风险的单步骤任务采用快速推理
* **THEN** 生效策略允许采用最小化计划及较低的思考预算
* **THEN** 支持推理控制的模型请求使用最低可用推理强度或关闭可选思考
* **THEN** 强制完成准则和安全检查保持不变

#### Scenario: 深度推理评估多个方案

* **WHEN** 一个复杂任务采用深度推理
* **THEN** 生效策略允许生成多个候选策略、执行假设检查，并提供更高但仍受限的模型推理及反思覆盖范围
* **THEN** 所有新增的模型调用均计入该运行记录的预算

#### Scenario: 模型不支持推理控制

* **WHEN** 生效策略指定推理强度但当前 Provider、模型或传输没有声明对应能力
* **THEN** 系统不发送未经支持的参数
* **THEN** Agent 循环预算、安全门和完成验证仍按生效策略执行
